# Reproducibility notes

The root `README.md` is the authoritative figure-to-data manifest and contains
the end-to-end commands. This file records the repository policy:

1. `Data/` contains generated or externally obtained files only and is ignored
   by Git.
2. Every simulation table is generated by a script in `Codes/`.
3. Every plotter reads only `Data/` and writes only `Data/` by default.
4. `paper/figures/` stores the archived submission assets and is not used as a
   hidden source of numerical data.
5. Figure 4 external datasets are downloaded manually by the user according to
   `Data/README.md` and are never redistributed in this repository.

For a fast interface check, use a single seed where supported. For the Figure
2 and 3 simulations, set `COMPLETE_OR_SPARSE_QUICK=1`. Quick runs verify the
pipeline but do not reproduce the reported estimates.
